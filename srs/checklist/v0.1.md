# Validation Checklist v0.1 — MediTrack SRS

| ID | Item | Answer | Evidence | Where question came from |
| :--- | :--- | :--- | :--- | :--- |
| **CL-001** | Does each requirement contain only one “shall” or “may” statement? | | | Rule: Clear |
| **CL-002** | Is every requirement free of undefined vague words (e.g. “quickly”, “user-friendly”, “securely”, “normal”, “policy”)? | | | Rule: Clear |
| **CL-003** | Does every speed or time requirement state a number and a unit? | | | Rule: Testable |
| **CL-004** | Could a pass/fail test be written for every requirement? | | | Rule: Testable |
| **CL-005** | Are all requirements free of direct contradictions regarding appointment durations? | | | Rule: Free of contradictions |
| **CL-006** | Does the document state the exact lead time before an appointment when reminders are sent? | | | Rule: Complete / Risk: Missed appointments |
| **CL-007** | Does the document define the minimum cancellation notice required before an appointment starts? | | | Risk: Last-minute empty slots |
| **CL-008** | Does the document specify how simultaneous booking requests for the same slot are resolved? | | | Risk: Double booking concurrency |
| **CL-009** | Does the document state the minimum number of concurrent users supported during peak Monday morning hours? | | | Risk: Peak load crash |
| **CL-010** | Does the document specify the exact encryption standard for storing medical records? | | | Risk: Data breach / DPO |
| **CL-011** | Does the document specify accessibility standards (such as minimum font size or screen-reader support) for elderly users? | | | User: Patient (Elderly) |
| **CL-012** | Does the document state how emergency walk-in patients are prioritized over standard bookings? | | | User: Receptionist |
| **CL-013** | Does the document allow doctors to block off unavailable time slots on their schedules? | | | User: Doctor |
| **CL-014** | Does the document allow the clinic administrator to configure clinic working hours? | | | User: Clinic administrator |
| **CL-015** | Does the document specify which user roles are permitted to view patient medical records? | | | User: Data protection officer |
| **CL-016** | Does the document define the exact system behavior when a patient attempts to book a fourth active appointment? | | | Rule: Complete |
